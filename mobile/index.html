Operational Modes via Type-C
Mode 1 • Workstation to Phone Audit
Audit Android & iPhone from PC / Laptop
Connect any smartphone to the Ghost-OS workstation via a Type-C cable to audit battery health, SoC silicon, and hardware serials.
  1. For Android: Enable Developer Options → USB Debugging, connect via USB-C cable.
  2. For iPhone / iPad: Connect via USB-C cable and tap "Trust This Computer" on the screen.
  3. Run Scan-Phone.cmd (Windows) or python -m ghost_core.scanners.phone_scanner.
  4. Generates tamper-evident Mobile Certificates with battery cycles and SoC specifications.
Mode 2 • Direct Phone OTG (Phone as Host)
Plug Pendrive Directly into Phone Type-C
Plug the physical SanDisk Type-C drive directly into your Android phone or iPhone 15/16 USB-C port.
  1. On Android: Open Files or Termux. Run sh Launch-GhostOS-Android.sh to audit the phone directly and write JSON reports to the drive.
  2. On iOS (iPhone 15/16 / iPad): Open the Files app → Select GhostVault under Locations → Tap any certificate in reports/certificates/ to view offline in Safari!
  3. Open START_HERE.html directly in your mobile browser with zero installation.
Mode 3 • Wireless Local Mobile Dashboard
Monitor & Control Workstation from Phone
Access the real-time Ghost-OS Admin Dashboard from your phone's Safari or Chrome over local Wi-Fi or phone hotspot.
  1. On the host PC/laptop, launch Launch-GhostOS-Remote.cmd.
  2. Connect phone to the same Wi-Fi or laptop mobile hotspot.
  3. Open phone browser and navigate to http://<laptop-ip>:8000.
  4. Full access to Fleet Inventory, real-time hardware gauges, and Ghost-AI Copilot.
